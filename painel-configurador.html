Projeto Xcode + GitHub Actions (iPhone .IPA)

Compilação na nuvem macOS gratuita do GitHub para instalar apps no iPhone usando Windows

Pronto para Compilar (.xcodeproj + GitHub Workflow)
1. Personalizar Parâmetros do App iOS

Ajuste o nome, Bundle ID ou URL do sistema web. Você também pode informar esses valores direto no botão "Run workflow" do GitHub Actions.

2. Como Gerar e Baixar o App no seu iPhone (Passo a Passo)

Como o Windows não roda o Xcode localmente, o GitHub Actions aluga um Mac gratuitamente na nuvem e gera o arquivo SmartSigmaApp.ipa para você.

1

Suba esta pasta para o seu GitHub

Execute o arquivo PUBLICAR_NO_GITHUB.bat na pasta do projeto ou suba os arquivos para um repositório no seu GitHub.

2

Aguarde 2 minutos na aba "Actions" ou "Releases"

O workflow .github/workflows/build-ipa.yml roda um servidor macos-latest com Xcode, compila o projeto SwiftUI e publica o arquivo SmartSigmaApp.ipa automaticamente na aba Releases do seu GitHub.

3

Instale o .ipa no iPhone (Sideloadly / AltStore / SideStore)

No Windows, abra o Sideloadly (gratuito em sideloadly.io), conecte o iPhone no USB, arraste o SmartSigmaApp.ipa baixado do GitHub, coloque seu Apple ID e clique em Start. No iPhone, vá em Ajustes → Geral → Gestão de VPN e Dispositivo e confie no app!
